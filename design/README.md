# Design references

Screenshots exported from the client-approved Figma file, used as visual reference while building.

- One image per page (and per breakpoint, if provided), e.g. `home-desktop.png`, `about-desktop.png`.
- Pages: Home, About, Services, Support, Contact, Booking, Privacy, Cookie policy.
- Desktop design width is 1600px.
- These files are for reference only; they are not served by the website. Images used on the site go in `public/images/`.
